Privacy Policy

Job Tracker · Last updated: November 23, 2026

Who this applies to

Job Tracker is a private, single-user tool. Its only user is the person who built and runs it. It is not offered to anyone else.

What data is accessed

With the owner's permission through Google OAuth, the tool reads email messages in the owner's own Gmail account so it can find job-application emails. It also adds a label to messages it has processed.

How the data is used

  • Emails are processed on the owner's self-hosted automation server. A language model running on that same server classifies them.
  • Only short details are stored, in the owner's private Notion workspace: company, role, dates, status, and a one- or two-sentence summary.
  • A short notification is sent to the owner's private Discord channel.

What is not done

  • No data is sold, shared with, or transferred to anyone else.
  • No data is used for advertising, and none is used to train AI models.
  • No email content is sent to any third-party AI service.

Google API Services

Job Tracker's use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
